# MG7
## Devlog
For TreeOfBirds, I used a _birds array, and put 4 normal Sparrow that not include Sparrow_Start. Using for loop to check each birds with player's distance. When player approaches the tree, use SetActive(true) to let birds appeared. For the Array, _birds array let me put these Sparrow in one variable, and use for loop to check all Sparrow. It doesn't need to write code for every Sparrow. And for Vector, seed's space uses Vector3.left and Vector3.up. And use TransformDirection(). This direction will change by player themself.
